# MyPlay

## 应用框架

```text
┌──────────────────────────────────────────────┐
│ L1 表现层（按需，窗口销毁即消失）               │
│    GPUI 窗口：设置/信息/日志 三个页面            │
│    只做：读快照渲染 + 发意图                    │
└───────────────▲──────────────┬───────────────┘
        快照/事件│              │意图(Start/Stop/Toggle/Close)
┌───────────────┴──────────────▼───────────────┐
│ L2 前端适配器（常驻）                          │
│  · 托盘：图标/菜单/tooltip ← 只收发消息          │
│  · 窗口管理：按需创建/销毁窗口                   │
└───────────────▲──────────────┬───────────────┘
        快照    │              │意图
┌───────────────┴──────────────▼───────────────┐
│ L3 核心状态机 Core（常驻，唯一真相源）           │
│  · 状态：Idle / Starting / Running / Stopping / Error
│  · 拥有：Settings、日志环形缓冲、播放快照、统计
│  · 拥有 ReceiverService（含当前通道）
│  · 事件归一：raw event → 标准 StateChange
│  · 策略：重启、端口冲突、错误上报、持久化
└───────────────▲──────────────┬───────────────┘
      事件流    │              │命令
┌───────────────┴──────────────▼───────────────┐
│ L4 通道适配器（常驻，可并行/互斥）              │
│  · MiPlay：FusionPlay SDK                    │
│  · AirPlay：fusionplay_core（DMR/AirPlay）    │
│  · DLNA：core DMR + 本地播放器（拉流/解码/出声） │
│  统一 trait：start/stop/toggle + EventStream   │
└──────────────────────────────────────────────┘
```
